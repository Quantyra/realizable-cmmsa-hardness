# Numbered occurrence producer, unary codec, and bounded-runtime construction

This v9 successor preserves the captured owner-prefix numbering, original-plus-gadget row order, finite 3Lin consumer, degree and overlap transfers, exact violation-count identity, variable bound, unary input/output parser, output validator, serializer, and malformed-input fallback. The concrete serializer has a proven candidate output-size bound, but no runtime or `Complexity.FP` theorem is claimed.

The unary wire format is `encodeWord n = true^n ++ [false]`; an input is the encoding of `[N,m]` followed by exactly four words for each row. The raw parser preserves all row occurrences and repeated variable names. The source now includes uncompiled semantic decoder lemmas proving that every numeral returned by a successful raw decode is at most the input bit length, and that the number of decoded numerals is at most that length. Consequently the two headers and all row fields in any successful `decodeInputBits` parse satisfy the same bound; in particular, the parsed row count m is at most L. These bounds are about the semantic decoder only and do not yet establish a Cobham runtime invariant. A malformed or partial final word enters the invalid state and is mapped to the fixed valid fallback `V=3`, one row `(0,1,2,false)`.

The actual producer program will use bounded loops over those unary counters. First scan rows in increasing row ordinal and the three slots in increasing coordinate ordinal. For each source owner, append the matching slots to its occurrence list in that exact order; the owner size is the list length and each occurrence's ordinal is the actual index in that nodup filtered list. Then enumerate each owner's local variables in the source definition's sum order: `Fin (size v) × Fin (FixedPortCycleFamily.predecessor+1)` first, then `edgeList (size v) × Fin 5`; tag the first block as a port variable and the second as an internal variable. Concatenate the owners in `Fin N` order. The representative edges are enumerated by the pinned `famRotFn`/`edgeList` program at the fixed algebraic parameter `p=2X`; their exact order is retained.

Emit rows in the exact actual source order: every original equation occurrence first, then each owner in increasing order, its `edgeList` in the pinned representative-list order, and each equality gadget's rows in its local list order. The exact replacement-dart count is 9 D m: there are 3m original coordinate slots, D local ports per slot, and three replacement darts per port. This count is the schedule to use in loop and accumulator bounds. For each of the three output coordinates, form the actual tagged variable using the owner ordinal and either the occurrence-port tag or edge/internal tag. Find its output index by a bounded scan of the concrete concatenated `variableList`. The proved nodup/membership lemmas identify the unique index found by that scan with the existing `variableIndexEquiv`. Emit the exact unary output words `[V,M]` followed by every row's three indices and rhs bit. This table scan is deliberately the same list-derived numbering used by the semantic source, rather than a separately chosen equivalence.

The bounded-algebra implementation will encode the parser state, row/slot/owner/edge/local-row counters, finite tag codes, and scratch/output vectors with the pinned fixed-arity `Cobham.Vec` encoding. Its finite transitions use `tableFn`, constants, concatenation, and fixed-width projections/take/drop. Every data-dependent loop is a call to the bounded iterator with a unary counter derived from the parsed input; there is no unclocked recursion over an input list. The `famRotFn_mem_FP` certificate at `2X` supplies the actual representative-list step. The inner row-to-variable lookup scans a list of O_D(L) entries for each of O_D(L) rows, so scratch tag/output state is bounded by C_D(L+1)^2; counting and numbering are fixed-depth bounded scans. Choose the polynomial clock after translating the concrete loop nesting, with a generous `C_D(L+1)^4` bound for every clock prefix. The state bound is for every intermediate accumulator and clock prefix, including malformed fallback and the absorbing completed state, as required by `iterFn`.
