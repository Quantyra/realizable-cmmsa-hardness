# Numbered occurrence producer: concrete scan-machine increment

This v12 successor preserves the semantic numbered producer, output validator, parser bounds, degree and overlap transfers, violation-count identity, variable bound, fixed legal malformed-input fallback, and the exact upstream unary format. It replaces v11's semantic-output transition with explicit owner, cloud-dart, and tag-generation transitions. The source remains uncompiled and unaccepted.

The main `State` has eighteen independently framed fields: phase; unread bits; unary count; decoded words; slot cursor and ordered source-slot trace; owner and owner-scan cursors; owner sizes, current occurrence accumulator, and completed owner occurrence lists; port occurrence and port-label cursors; variable tags; current cloud representatives and completed representative clouds; and edge/internal-label cursors. The independent length prefixes give fixed field boundaries while values vary. `TagLookupState` separately stores the ordered tag vector, requested tag, cursor, result, and completion bit; each lookup transition examines one current tag and advances by at most one.

The parser consumes one bit per step and appends a numeral only on a false delimiter. Once its exact parser accepts the input, the slot scanner walks the input's original rows and three coordinates in row-major order and records `(row, coordinate, owner)`, preserving duplicate rows and repeated variable names. For each owner in increasing order, the next scan walks that slot trace and retains exactly entries with the current owner. Their stored indices are `3*row+coordinate`, in the exact filtered source order; the list length is the owner's cloud size. The port phase then emits tags `(0, owner, occurrence ordinal, local port)` in occurrence-major and port-major order.

For that same owner, the cloud-dart phase scans the literal product order `Fin n × Fin D × Fin 3` using cursor decomposition `d=cursor%3`, `q=cursor/3`, `v=q/D`, and `j=q%D`. The numeric rank is `j+D*v`, matching the pinned `finProdFinEquiv` ordering. External darts call the fixed `Complexity.algBase.famRotFn (2X)` string program; forward/backward cycle darts use the explicit modular successor/predecessor. The transition retains a dart exactly when its source rank is strictly below the returned reverse endpoint's rank. That preserves parallel dart orbits and drops loops. At size zero the loop has zero iterations and makes no family call. For each retained representative, the internal-tag phase emits `(1, owner, edge ordinal, t)` for `t=0..4`, then advances to the next owner. Thus generated tags use the actual per-owner order: all occurrence-port variables followed by representative-edge internal variables.

The fixed-family `FP` witness is `Complexity.FinBase.famRotFn_mem_FP` at `2X`. `familyRotationProgram_mem_CobhamFP` embeds that exact witness using the pinned `Complexity.FP_subset_CobhamFP`; this licenses that subroutine for a later Cobham composition. The exact call equality is `famRotFn_eq`; its fit-level premise is discharged using the pinned `fitLevel_le`, because `fitLevel n ≤ 2n = eval (2X) n`. The `familyRotationValue` helper extracts the unary pair's two numeral lengths and proves equality to the library `famRotVal` for positive cloud size. This certifies the fixed family subroutine only, not the containing phase machine or its global iteration.

For a future iterator proof, let `L` be the raw unary input length and keep `D` fixed. On reachable states, parsed row and variable counts are at most `L`; the slot trace, owner occurrence lists, scanned darts, representatives, and tags each have at most `O_D(L)` entries, with each stored numeral at most `O_D(L)`. Independent length frames therefore give an intended all-prefix state encoding bound `C_D (L+t+1)^3` for clock prefix `t`; this loose target also covers the accumulated lists without needing a sharp final-output bound. The source-level output bounds remain `V ≤ 26 D m` and `M ≤ (18 D+1)m`, with raw output length at most `2000(D+1)^2(m+1)^2`. These estimates are obligations for the later reachable-state and Cobham iterator proofs, not theorems supplied by this increment.

The scheduler reaches `tagsComplete` after the variable-tag list has been generated. It does not yet produce serialized output. The local representative tuples have not yet been proved equal, in list order, to the typed source `ActualEqualityCloud.edgeList`; the port/internal tag list has not yet been connected to `variableList`/`variableIndexEquiv`; row-to-tag bounded scans, gadget row emission, output serializer equality with `totalProducer`, every-prefix polynomial state bounds, and the whole producer's Cobham/`Complexity.FP` proof remain open. In particular, an FP/Cobham witness for `famRotFn` alone does not imply a certificate for this phase machine.

The malformed-input phase remains explicit and absorbing; the separately captured semantic total producer maps malformed inputs to the fixed legal fallback `V=3`, one row `(0,1,2,false)`. Connecting that fallback and the valid emitted output to one completed runtime is still outstanding. The input parser intentionally permits repeated variables and repeated rows; only generated-output validation enforces row support promises.
