Fix \(U=H\oplus A\), \(Q\le W'\le A\), and a nonempty family \(Z'\) of \(d\)-spaces \(R\) with \(Q\le R\le W'\). For each such \(R\), every transverse \(d\)-space \(L\le H\oplus W'\) containing \(Q\) is uniquely the graph of \(\phi:R\to H\) with \(\phi|_Q=0\). The fiber is \(\mathrm{Hom}(R/Q,H)\), so it has constant positive size \(2^{J(d-a)}\). The domain is \(H+L=H+R\), independent of \(\phi\). If the selected label on every such domain takes the prescribed right-hand-side values on the equation vectors spanning \(H\), its restriction to \(H\) is one fixed \(\lambda\). The extension \(G(h+x)=\lambda(h)+g(x)\) is linear, preserves codimension, and has the same agreement event on each graph as \(g\) has on \(R\). Thus uniform agreement is exactly preserved, including its rational denominator.

The uniform-advice marginal derivation in the side-extension argument also checks out. Complements of \(H\) are graphs of maps from a fixed \(n\)-space to \(H\); for fixed \(H\)-disjoint \(Q\), exactly \(2^{J(n-a)}\) contain it. Uniform complement-then-\(Q\) therefore has uniform marginal on all \(H\)-disjoint \(a\)-spaces.
