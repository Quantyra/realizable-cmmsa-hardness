# Decoder normal form milestone

This successor imports the immutable scanner core from capture `local-three-sat-binary-codec-capture-20261012-v1` and the pinned local `Complexitylib.SAT.ThreeSAT` API. It defines `decodedOutput` by the authoritative total restricted decoder: failed `CNF.decode3?` parses return `[]`; successful parses emit the framed formula payload. This establishes a semantic normal form independently of the still-unproved equality with the scanner's `convert` function.

For a literal `l`, the framed output length is `2 + 2*l.var`. For a clause of exactly three literals, the clause marker, three signs, three name terminators, and framed name digits give length `7 + 2*variableMassClause`. Summing the clauses and adding the final false marker gives `1 + 7*phi.length + 2*variableMass phi`. The source proves these length identities for the emitted syntax and proves that every decoded exact-three formula encoding has that output.

The all-input local-language theorem is stated through the library's `ThreeSAT.mem_language_iff_decode3`: membership is equivalent to a successful restricted decode with a satisfiable typed formula, and that successful case emits `emitFormula phi`. The empty formula is valid and maps to `[false]`; a failed restricted decode maps to `[]`. The emitter always includes its terminal false bit, so these two cases are separated.

The captured finite scanner is not yet proved equal to `decodedOutput`. The open scanner theorem is `scannerMatchesDecoder : forall w, convert w = decodedOutput w`. Proving it requires both directions between the state machine's accepted token stream and local `CNF.decode3?`; a forward-only encoder roundtrip is insufficient for malformed words. Accordingly, this offer does not claim the actual scanner's semantic endpoint or acceptance of the local 3SAT language.

The exact local sign convention remains `Lit.eval alpha ell = (alpha.get ell.var == ell.sign)`, with true positive, false negative, and finite lists defaulting absent variables to false. The sparse-name argument uses `g(n)=2^n-1`, whose canonical binary digits are n true bits. The two satisfaction directions must use finite assignments: extend a local list to the image of g (false elsewhere), and restrict an upstream assignment to a local list of length `maxVar(phi)+1`.

The runtime route is pinned by planning commit `493b6d3`, section “Concrete bounded-string implementation of the runtime joins”. It supplies a concrete bounded-string/`RecNotation` route through `tableFn`, append/take/drop and bounded iteration, plus `reverse_mem_FP` and `CobhamFP_subset_FP`. Those APIs can establish an actual `FP` witness only after the scanner/reference function equality and output bounds are proved. This file does not insert a caller-supplied FP premise or assert a TM witness.
