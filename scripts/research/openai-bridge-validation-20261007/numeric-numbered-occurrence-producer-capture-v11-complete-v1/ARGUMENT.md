# Numbered occurrence producer and bounded-runtime increment

This v11 successor preserves the captured owner-prefix numbering, actual row order, degree/overlap/violation transfers, unary input/output parser, serializer, and malformed-input fallback. It adds a seven-field framed phase state and concrete one-step transitions for unary parsing, source-slot scanning, and output-equation emission. It also adds the pinned finite-base rotation string program at the fixed polynomial `2X`, proves its `FP` membership from the upstream theorem, and discharges the family equality's fit-level premise using `fitLevel_le`.

The runtime state fields are `phase`, unread bits, current unary counter, decoded word vector, source-slot cursor, ordered slot trace, and output-bit buffer. Each field is independently length-prefixed; the state shape has exactly seven fields. Parsing consumes one bit per step and appends a numeral only at a false delimiter. At end of input it rejects an unterminated unary word and routes malformed input to the fixed legal fallback `(V=3, M=1, row=(0,1,2,false))`. The slot-scan phase advances one of the `3m` original row-coordinate slots per transition and records its actual row ordinal, coordinate ordinal, and owner value. The emit phase appends one full unary-encoded output equation per transition. `done` and `invalid` are absorbing phases.

The family primitive is the exact pinned `Complexity.algBase.famRotFn (2X)`. For positive cloud size, its encoded unary call is proved equal to the unary encoding of `algBase.famRotVal` at the same numeric tuple. The bound follows from `algBase.fitLevel_le`: `fitLevel n ≤ 2n = eval (2X) n`. No caller-supplied fit-level premise is used. Cloud size zero has no darts and therefore makes no family call.

This is an actual phase/accumulator source increment, not an end-to-end bounded producer. The slot scanner currently starts from an already parsed semantic `Input`; emission currently reads the existing semantic `output input`. Thus occurrence-list construction, local port/representative-edge enumeration, encoded tag lookup, per-edge family calls in the producer loop, output equality with `totalProducer`, every-prefix polynomial accumulator bounds, and a `CobhamFP_subset_FP` construction remain unproved. The state framing and transition lemmas do not yet give a Cobham implementation or an FP certificate. The row-count bound remains `(1+18D)m`, replacement darts are `9Dm`, and the variable bound remains `2V≤51Dm` from the preserved semantic source.

The output parser preserves repeated input rows and repeated input variable names. Only the generated output validator checks nonempty rows, coordinate range, row injectivity, degree ten, and overlap one. This distinction remains necessary for the input language and the generated-source promise.
